🚀 Portfólio de Automação com TypeScript

Repositório criado para estudos e desenvolvimento de conhecimentos em TypeScript, com foco na construção de uma base sólida para automação de testes.

⚙️ Como executar
1. Clone o repositório
git clone https://github.com/vitorsantabi/portifolio-automocao-com-typescript.git

2. Entre no diretório
cd portifolio-automocao-com-typescript

3. Instale as dependências
npm install

4. Compile o projeto
npx tsc

💻 Exemplos
Criando um tipo personalizado
type Usuario = {
  nick: string;
  age: number;
};

Criando uma função com parâmetros tipados
function verificarIdade(idade: number): string {
  if (idade >= 18) {
    return "Usuário maior de idade";
  }

  return "Usuário menor de idade";
}
